使用说明书

快速开始

  1. 配置 AI 模型：进入「AI 配置」页面，添加至少一个模型（支持 OpenAI / Claude / DeepSeek 等），设置为聊天用途。
  2. 设置角色：进入「角色设置」页面，编辑角色名称、性格、背景等信息。可使用 AI 自动生成。
  3. 开始聊天：进入「聊天」页面，选择一个会话即可开始对话。

核心功能

  • 会话管理：支持多会话、会话归档/恢复、消息编辑/删除、上下文压缩。
  • 角色系统：角色卡定义人格，运行时状态自动追踪情绪/关系/场景，记忆自动抽取。
  • 世界书：绑定世界观设定，支持多源上下文召回（用户消息 + 助手回复 + 历史 + 场景状态自动触发）。
  • 知识库：上传文档建立向量索引，AI 对话时自动检索相关知识。
  • 技能/工具：扩展 AI 能力，支持自定义技能脚本和工具调用。
  • 工作流：自动化任务流程，支持关键词触发和手动执行。

频道接入

  • QQ：通过 NapCat/Lagrange 等协议端接入，支持私聊和群聊。
  • Telegram：通过 Bot Token + Webhook 接入。
  • 飞书：支持 Webhook 和 WebSocket 两种模式。
  • Web：内置 Web 聊天界面，支持 PWA 推送通知。

AI 模型

  • 支持多模型配置，每个模型可设置不同用途（聊天/记忆/规划/摘要）。
  • 支持故障转移：主模型不可用时自动切换备用模型。
  • 支持 OpenAI 兼容、Claude、Gemini、DeepSeek、硅基流动等多种协议。

{{ $t('runtime.character_runtime') }}

  • 情绪系统：自动追踪角色情绪状态和强度。
  • 关系系统：自动维护角色与用户的好感/信任/熟悉度等关系指标。
  • 场景状态：自动识别当前地点、剧情弧、氛围等，用于世界书触发。
  • 记忆系统：自动从对话中抽取长期记忆，跨会话保持。

调试台

  • 「API 文档」按钮查看所有可用接口。
  • 「日志」查看 Gateway 事件日志和 MCP 工具调用记录。
  • 「Token 用量」监控 AI 模型调用消耗。

常见问题

  • AI 不回复：检查 AI 模型配置是否正确，API Key 是否有效。
  • 世界书不触发：检查条目是否启用、关键词是否匹配、角色是否绑定。
  • QQ 消息收不到：检查协议端（NapCat）是否正常运行，Webhook 地址是否正确。
  • 角色记忆丢失：检查记忆服务是否正常，可手动在角色管理页面查看和添加记忆。
提示：更多详细文档请访问项目文档站点，或在调试台点击「API 文档」查看完整接口说明。
